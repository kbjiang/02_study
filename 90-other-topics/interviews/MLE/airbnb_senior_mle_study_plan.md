## 5. Official Loop Intelligence & CodeSignal Coding Rubric

* **Recurring Themes Across 2026 Airbnb Senior MLE Loops:**
  * Relentless probing on **why** an architecture was chosen over simpler baselines.
  * Balancing **precision, recall, serving latency, and infrastructure cost**.
  * Handling **position bias, cold-start items, noisy labels, and offline-vs-online metric divergence**.
  * Practical coding focused on **string manipulation, text parsing, tries/prefix matching, hash maps, and edge-case precision** (e.g., floating-point Coin Change, Document Redaction, String Table Formatting).
* **Airbnb's 5-Step CodeSignal Evaluation Flow (45-Minute SWE Round):**
  1. **Clarify the problem** (bounds, nulls/empty inputs, precision, tie-breakers) before coding.
  2. **Define clean interfaces** (function signatures, input/output types, modular helpers).
  3. **Think out loud** continuously so the interviewer follows your logic.
  4. **Test & debug proactively** (write and execute unit tests in CodeSignal covering normal and edge cases).
  5. **Discuss limitations & trade-offs** (time/space complexity, alternative data structures, scaling).
